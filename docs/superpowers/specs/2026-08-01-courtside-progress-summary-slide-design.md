# COURTSIDE Progress Summary Slide Design

## Objective

Add one final slide to the existing COURTSIDE midway Canva presentation. The
slide summarizes the current 40% project progress, the problems encountered,
and the immediate corrective actions. It supports a solo 20-minute midway
presentation and provides a clear closing transition into questions.

## Placement

- Add the slide after the current final workflow slide.
- The new slide becomes page 39.
- Preserve all existing 38 slides and their order.

## Visible Content

### Title

`สรุปความก้าวหน้าและปัญหาที่พบ`

### Overall Progress

Display `ความก้าวหน้าปัจจุบัน 40%` as the primary visual callout.

### Weighted Progress Breakdown

| Workstream | Progress contribution |
| --- | ---: |
| Authentication และสิทธิ์ผู้ใช้ | 8% |
| Public Search และรายละเอียดการแข่งขัน | 8% |
| การสร้าง ตรวจสอบ และเผยแพร่รายการ | 12% |
| การสร้างทีมและสมัครแข่งขัน | 8% |
| โครงสร้างฐานข้อมูลและการจัดการสื่อ | 4% |
| **รวม** | **40%** |

The percentages represent contribution to the whole graduation project, not
the completion percentage inside each workstream.

### Problems Found

- การกำหนดสิทธิ์และสถานะของหลายบทบาทมีความซับซ้อน
- ต้องทดสอบ Workflow ตั้งแต่สร้างรายการจนถึงอนุมัติทีมเพิ่มเติม
- ตารางแข่งขัน Bracket ผลคะแนน และการแจ้งเตือนยังไม่เสร็จ

### Corrective Actions

- เพิ่ม Automated Test และข้อมูลตัวอย่างสำหรับเดโม
- พัฒนาโมดูลที่เหลือเป็นส่วนย่อยตามลำดับความสำคัญ
- เตรียมบัญชีและข้อมูลสำรองสำหรับวันนำเสนอ

## Layout

- Use a single 16:9 slide in the existing COURTSIDE blue-and-orange visual
  language.
- Place the title across the top.
- Use the left side for the 40% callout, problems, and corrective actions.
- Use the right side for a white progress table with restrained borders.
- Keep the information flat and readable; avoid nested cards and gradients.
- Use orange for progress emphasis, dark navy for the background, and white
  for body copy.
- Maintain presentation-safe font sizes and prevent any text or table overlap.

## Acceptance Criteria

- The Canva deck contains exactly 39 slides after the change.
- The original 38 slides remain in their existing order.
- The progress contributions sum to 40%.
- The slide clearly separates completed progress, problems, and corrective
  actions.
- No placeholder text, unintended wrapping, clipping, or overlap remains.
- Canva reports that all changes are saved.
